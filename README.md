# India Tools
An independent public tools website by Sarada Sutar.

## Available in v0.1
- Gregorian monthly calendar, previous/next month and today navigation
- Calendar print stylesheet
- Searchable tool cards with empty states
- Days-between-dates calculator with reversed-date validation
- Percentage calculator
- Responsive ivory/teal interface and labelled controls

Open index.html in a browser, or publish the repository root using GitHub Pages.
No dependencies, account, database or Apps Script endpoint is required.

## Publish
In repository Settings → Pages, choose **Deploy from a branch**, **main**, **/(root)** and Save, if not already enabled. GitHub's Pages screen reports the deployed URL. Source installation is separate from a verified deployment.

This starter's calendar is Gregorian. The existing Odia calendar, Kohinoor festival data, translations, reminders and administration have not been connected. Public data must be curated separately from private dashboard records.
